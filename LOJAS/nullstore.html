NULL Store

Informações gerais

A NULL Store é uma plataforma associada ao ecossistema homebrew do PS4, conhecida por apresentar um catálogo de conteúdos digitais.

Preços

Consulte as informações oficiais da plataforma. A disponibilidade e as condições podem variar.

📥 Como instalar

Requisitos:

  • PS4 com suporte a homebrew e ambiente desbloqueado.
  • Arquivo de instalação do Apollo em formato PKG.
  • Dispositivo USB, caso escolha instalar por ele.

Passo a passo

  1. Acesse a página oficial do projeto no GitHub.
  2. Desça até Releases > Latest > Assets e instale o PKG da loja.
  3. Transfira o arquivo para um dispositivo USB compatível.
  4. Conecte o USB ao PS4.
  5. Vá em GoldHEN > Debug Settings > Package Installer e instale a NULL Store.
  6. Após a instalação, abra a NULL pelo menu do console.
