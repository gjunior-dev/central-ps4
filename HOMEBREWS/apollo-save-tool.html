Apollo Save Tool

Um aplicativo homebrew para gerenciar arquivos de salvamento de jogos no PlayStation 4.

Faça backups, organize saves, aplique correções compatíveis e gerencie arquivos diretamente pelo console.

📌 O que é o Apollo Save Tool?

O Apollo Save Tool é um aplicativo desenvolvido por bucanero. Ele permite trabalhar com arquivos de salvamento de jogos do PS4 e também com cartões de memória virtuais de consoles antigos.

É um aplicativo independente: depois de instalado, suas funções são acessadas diretamente pelo PS4.

📥 Como instalar

Requisitos:

  • PS4 com suporte a homebrew e ambiente desbloqueado.
  • Arquivo de instalação do Apollo em formato PKG.
  • Dispositivo USB, caso escolha instalar por ele.

Passo a passo

  1. Acesse a página oficial do projeto no GitHub.
  2. Desça até Assets e instale IV0000-APOL00004_00-APOLLO0000000PS4.pkg
  3. Transfira o arquivo para um dispositivo USB compatível.
  4. Conecte o USB ao PS4.
  5. Vá em GoldHEN > Debug Settings > Package Installer e instale o Apollo Save Tool.
  6. Após a instalação, abra o Apollo pelo menu do console.

💡 Dicas e cuidados

  • Faça cópias de segurança antes de modificar saves.
  • Confira se o arquivo pertence ao jogo e à região corretos.
  • Não interrompa uma operação de importação ou exportação.
  • Leia as informações de cada opção antes de aplicá-la.
  • Não exclua arquivos de troféus sem entender as consequências.

❓ Perguntas frequentes

Preciso de computador para usar o Apollo?

Não. O aplicativo funciona diretamente no PS4.

O Apollo funciona em qualquer firmware?

A partir da versão 2.0.0, o projeto informa suporte independente de firmware. Porém, o console ainda precisa ter um ambiente compatível com homebrew.

Posso perder meus saves?

Operações incorretas podem causar perda de dados. Por isso, mantenha backups antes de fazer alterações.
