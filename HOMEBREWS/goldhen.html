📌 O que é o GoldHEN?

GoldHEN significa Gold Homebrew Enabler. É um projeto desenvolvido por SiSTRo para habilitar funcionalidades homebrew no PlayStation 4.

Ele não é um aplicativo PKG comum. É carregado no ambiente compatível do console e disponibiliza recursos que não existem no sistema original.

Entre suas funcionalidades estão servidor FTP, suporte a plugins, contador de FPS, configurações de desenvolvimento e ferramentas adicionais.

📋 Compatibilidade

A compatibilidade depende da versão do GoldHEN e do método utilizado para carregá-lo.

Consulte sempre a lista de firmwares indicada nas notas da versão que você pretende utilizar.

Importante: não considere que todas as versões do GoldHEN funcionam em todos os firmwares. Uma versão incompatível pode simplesmente não carregar.

📥 Como instalar o GoldHEN?

O GoldHEN é carregado por meio de um ambiente de desbloqueio compatível. O processo não é igual à instalação de um aplicativo PKG.

1. Identifique seu firmware

Consulte a versão do sistema em: Configurações → Sistema → Informações do sistema.

2. Confira a compatibilidade

Verifique se existe uma versão do GoldHEN compatível com seu firmware e com o método escolhido.

3. Consulte o método correspondente

Os métodos e ambientes disponíveis podem variar. Acesse nosso guia de Desbloqueios para consultar as informações organizadas por firmware.

🔓 Acessar guia de Desbloqueios da CENTRAL PS4 →

4. Confira o carregamento

Depois de utilizar um método compatível, confira se o GoldHEN foi carregado corretamente e se seus recursos estão disponíveis.

Não atualize o firmware do console apenas para tentar utilizar outra versão do GoldHEN. Pesquise a compatibilidade antes de qualquer alteração.

⚙️ Funções do GoldHEN

Conheça os principais recursos documentados pelo projeto. Alguns são serviços internos, patches ou opções técnicas, e não necessariamente botões individuais no menu.

1. Homebrew Enabler

Habilita a execução de aplicativos homebrew, desenvolvidos pela comunidade para o PS4.

2. Debug Settings

Disponibiliza configurações adicionais de diagnóstico e desenvolvimento que não aparecem normalmente no menu comum do sistema.

3. VR Support

Adiciona suporte relacionado a recursos de realidade virtual em ambientes compatíveis.

4. Remote Package Install

Permite receber pacotes de instalação pela rede, sem precisar transferir o arquivo diretamente por um dispositivo USB.

5. Rest Mode Support

Oferece suporte a determinados recursos do GoldHEN durante o modo de repouso.

O comportamento pode variar conforme a versão e os aplicativos utilizados.

6. External HDD Support

Adiciona suporte relacionado ao uso de dispositivos de armazenamento externo.

7. Official External HDD Format Support

Oferece suporte relacionado ao formato oficial de armazenamento externo utilizado pelo PS4.

8. Debug Trophies Support

Habilita recursos técnicos relacionados ao diagnóstico de troféus. Isso não significa que alterações serão reconhecidas pela PSN.

9. sys_dynlib_dlsym Patch

Modifica uma função interna utilizada para localizar símbolos de bibliotecas dinâmicas. É um recurso técnico importante para determinados aplicativos e plugins.

10. UART Enabler

Habilita suporte relacionado à interface UART, utilizada em comunicação e diagnóstico técnico.

11. Never Disable Screenshot

Evita determinadas restrições do sistema que desabilitam a captura de tela em algumas situações.

12. Remote Play Enabler

Adiciona suporte para recursos relacionados ao Remote Play em condições compatíveis.

13. FW Update Block

Oferece uma proteção relacionada ao bloqueio de atualizações de firmware. Não substitui a necessidade de conferir as configurações de atualização do console.

14. FTP Server

Permite comunicação entre o PS4 e outro dispositivo pela rede, utilizando o protocolo FTP. É utilizado para transferir e gerenciar arquivos.

Porta padrão: 2121.

15. BinLoader Server

Serviço técnico que permite receber payloads binários por meio da rede. É um recurso experimental e pode apresentar riscos de instabilidade.

Porta: 9090.

16. Klog Server

Disponibiliza registros internos do sistema para diagnóstico e análise técnica.

Porta: 3232.

17. CE-30391-6 Error CMOS Fix

Inclui uma correção relacionada ao erro CE-30391-6, associado a problemas de CMOS e informações de data e hora.

18. Integrated Cheat Menu

Disponibiliza um menu integrado para recursos de códigos e modificações compatíveis com determinados jogos.

A compatibilidade depende do jogo, da versão e dos arquivos utilizados. O projeto alerta que esse recurso é experimental.

19. Integrated FPS Counter

Permite exibir um contador de FPS, ou seja, quadros por segundo, ajudando a acompanhar o desempenho visual dos jogos.

20. Plugins Support

Permite utilizar plugins desenvolvidos para o GoldHEN, adicionando funcionalidades extras ao ambiente do console.

21. TitleId Label

Exibe informações de identificação do jogo, como seu Title ID, facilitando reconhecer cada título.

22. Scanlines Overlay

Adiciona uma sobreposição visual de linhas na tela, criando um efeito estético semelhante ao de telas antigas.

23. Internal PKG Installation Support

Adiciona suporte relacionado à instalação de pacotes armazenados no diretório interno /data/pkg, em condições compatíveis.

💡 Dicas e cuidados

  • Confira a compatibilidade antes de utilizar uma versão.
  • Evite misturar arquivos de versões diferentes.
  • Mantenha backups dos dados importantes do console.
  • Utilize aplicativos e plugins de fontes confiáveis.
  • Tenha cuidado com recursos experimentais.
  • Não interrompa operações importantes em andamento.
  • Nem todo homebrew funciona perfeitamente com o GoldHEN.
Alerta: o projeto informa que o BinLoader e o Cheat Menu possuem aspectos experimentais. Payloads incompatíveis podem causar travamentos ou mau funcionamento.

❓ Perguntas frequentes

GoldHEN é um aplicativo?

Não exatamente. É um Homebrew Enabler que habilita recursos adicionais no ambiente compatível do PS4.

⚠️ O que é Kernel Panic?

Kernel Panic é uma falha crítica no núcleo do sistema do PS4. Quando acontece, o console pode travar, reiniciar sozinho ou apresentar uma mensagem de erro.

Em consoles desbloqueados, pode ocorrer durante a execução de exploits, payloads, plugins ou por incompatibilidades.

Devo me preocupar?

Nem sempre! Um Kernel Panic isolado não significa que seu PS4 foi danificado. Porém, se acontecer frequentemente, vale investigar possíveis problemas de software ou hardware.

Dica: mantenha seus dados salvos em backup e evite usar arquivos incompatíveis com a versão do seu sistema.

Preciso carregar o GoldHEN novamente?

Em geral, depois de uma inicialização completa, é necessário carregá-lo novamente. O suporte ao modo de repouso pode alterar esse comportamento.

GoldHEN funciona em qualquer firmware?

Não. Cada versão possui sua própria compatibilidade. Consulte as notas oficiais antes de utilizar.

O GoldHEN pode causar travamentos?

Sim. Incompatibilidade de versões, plugins e recursos experimentais podem provocar falhas.

GoldHEN e Apollo Save Tool são a mesma coisa?

Não. O GoldHEN habilita recursos homebrew no sistema. O Apollo é um aplicativo voltado principalmente ao gerenciamento de arquivos de salvamento.

GoldHEN é desenvolvido pela Sony?

Não. É um projeto independente da comunidade, desenvolvido por SiSTRo.
